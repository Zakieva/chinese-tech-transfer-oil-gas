## Задача проекта

Систематизировать передовые китайские технологии для нефтегазовой отрасли и оценить применимость для российских компаний (в т.ч. Газпром, нефтесервис, строительство магистралей).

В каждой карточке:

- оригинальное китайское название технологии;
- описание принципа работы;
- результаты внедрения в КНР;
- вывод о применимости для российской нефтегазовой отрасли;
- ссылки на источники.

Тексты карточек готовит аналитик; координатор организует процесс и ведёт публичный каталог.

## Категории технологий

| Категория | Примеры |
|-----------|---------|
| **Сварка** | CPP900, роботизированная сварка, индукционный нагрев |
| **Ремонт** | Метод «цзунцзы», UV-CIPP, трехплунжерный насос KTZ600L |
| **Материалы** | 3PE-адгезив, графеновые покрытия, биметаллические трубы |
| **Неразрушающий контроль** | PAUT, внутритрубный дефектоскоп, оптоволоконный мониторинг |
| **Разработка недр** | Газлифт, скважинные электронагреватели |
| **Беспилотники** | «Цифровой страж» — дроны и роботы для патрулирования |
